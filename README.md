# DUSTVECTOR 尘线

可离线运行的 HTML 第一人称射击小游戏。沙漠中继站、三波无人机、掩体、弹药补给与战绩结算。

## 直接开始

双击 `dustvector.html`，用 Chrome 或 Edge 打开，点击「开始行动」。这个单文件已包含游戏代码、样式、字体和交互动效，无需安装依赖，也不请求外网。

开发版本也可以运行：

```powershell
npm start
```

然后访问 `http://127.0.0.1:5173`。分文件版 `index.html` 建议通过本地服务打开；单文件 `dustvector.html` 可直接双击。

## 操作

| 操作 | 键位 |
| --- | --- |
| 前后左右移动 | W / A / S / D |
| 环视与瞄准 | 鼠标移动，或方向键 |
| 连续射击 | 按住鼠标左键，或空格 |
| 冲刺 | 按住 Shift |
| 换弹 | R |
| 暂停 / 继续 | Esc 或 P |
| 全屏 / 声音 | 顶部右侧按钮 |

开始后浏览器会请求锁定鼠标。若浏览器拒绝，可以按住画面拖动瞄准，也可以用方向键。切换窗口、切换标签或失去鼠标锁定时游戏自动暂停。

手机支持左侧虚拟摇杆移动、右侧拖动瞄准、独立射击和换弹按钮。横屏拥有更宽的视野。

## 任务规则

- 标准行动共三波：4、6、8 架无人机；高压行动为 5、7、9 架，敌人生命、移动与攻击也会增强。
- 无人机发射可躲避弹丸。箱体、建筑和边界均参与真实碰撞及射线遮挡。
- 初始生命 100，弹匣容量 24，备弹 120；空弹匣自动换弹。换弹时不能射击。
- 绿色补给恢复生命 35，橙色补给增加备弹 36。每波结束恢复生命 20、发放备弹 48，生命不超过 100。
- 三波全部清除后胜利，生命降至零则失败。结算显示得分、击毁数、命中率和时间。最高分存于当前浏览器本地。

## 文件与实现

- `game-core.js`：独立模拟逻辑、碰撞、射线、敌人、弹丸与波次。
- `game.js`：原生 WebGL 渲染、程序化三维地图和武器、输入、合成音效、应用状态。
- `game.css`：战术终端风格及手机布局。
- `assets/`：用户指定的 design-taste-frontend skill 原始素材，保持不修改。交付压缩包只收录运行所需文件。
- `fonts/`：本地 Epilogue 与 JetBrains Mono 字体，附 OFL 许可证。
- `build.py`：生成单 HTML 和源码压缩包；`npm run build` 可以重新打包。

不使用第三方游戏引擎、在线图片、在线音频或 CDN。需要支持 WebGL 的浏览器。

## GitHub Pages 部署

运行 `python build.py` 会生成可直接双击的 `dustvector.html`，以及用于静态托管的 `dist/index.html`。部署产物只包含游戏，不包含源码、浏览器缓存或本地输出。

仓库包含 `.github/workflows/pages.yml`：推送到 `main` 后先运行机制测试，再构建并部署到 GitHub Pages。在仓库 Settings → Pages 中，将 Source 设置为 GitHub Actions。后续推送会自动更新网站。

## 素材与字体

游戏场景、模型与音效由项目代码生成。Epilogue 和 JetBrains Mono 字体以 SIL Open Font License 分发，各自许可文件保存在 `fonts/` 中。`assets/` 内只收录本项目实际使用的原始设计运行时。

## 验证

```powershell
npm test
```

机制测试覆盖射线、墙体遮挡、碰撞防穿墙、斜向移动速度、换弹及暂停、三波胜利、失败、敌人弹丸、补给和高压难度。
